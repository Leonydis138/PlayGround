CIDR notation in, real numbers out.

Host conventions, stated rather than assumed:

/32 is a single host (RFC 3021 host route) - 1 usable address.
/31 is a point-to-point link (RFC 3021) - 2 usable addresses under RFC 3021, but many vendors still reserve the network and broadcast addresses. If your gear is old, treat a /31 as 0 usable hosts.
/30 and larger use the classic rule: total minus 2 (network + broadcast).
